# Ultimate Animated Animals

Artwork by **Quaternius**. [Original listing](https://quaternius.com/packs/ultimateanimatedanimals.html).

12 animated animals including alpaca, bull, cow, deer, donkey, fox, horses, husky, shiba inu, stag and wolf.

Each original glTF embeds its buffers and animation clips. Preserve the rig and clips as one model; choose clip names from the file rather than guessing.

Original filenames, image dimensions and related file paths are preserved.
