# Ultimate Gun Pack

Artwork by **Quaternius**. [Original listing](https://quaternius.com/packs/ultimategun.html).

Forty low-poly guns (pistols, revolvers, submachine guns, shotguns, assault rifles, bullpups and sniper rifles) in `Guns/`, and fifteen attachments (scopes, silencers, grips, stocks, bayonets, bipod, tripod and flashlight) in `Accessories/`.

The original download ships these models as `.blend`, `.fbx` and `.obj` only. Each `.glb` here was exported from the creator's `.blend` file with its geometry and flat-colour materials unchanged, keeping the original file name. The guns are modelled side-on, barrel along +X, with the grip near the origin.
