# Sushi Restaurant

Artwork by **Quaternius**. [Original listing](https://quaternius.com/packs/sushirestaurantkit.html).

A restaurant kit with food, decoration, modular interiors and animated chef characters, including held knife and pan variants.

All models use original embedded glTF buffers. Each character includes its original animation clips. The source atlas and help image are kept at the pack root.

Original filenames, image dimensions and related file paths are preserved.
