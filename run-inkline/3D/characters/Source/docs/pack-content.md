# Pack contents

12 character GLBs share an 18-bone rig. Each contains the same 85 named clips.

| Animation category | Clips |
| --- | ---: |

| interaction | 6 |

The pack also contains 64 procedural effects and 64 transparent sprite sheets. Each sheet has eight 384×384 frames in a 4×2 layout.

Three assembled scenes are supplied as GLB, placement JSON, and editable Blender files. Industrial District provides the playable demo routes. Service Yard and Roof Works are visual assemblies for inspection and reuse.
