# Evidence files

Read [the current verification index](README.md) first. It separates the 1.3
correction evidence from the historical reports.

The pack keeps report images and metadata in the same directory structure as
the source project. Correction reports and images are in `correction/`.
Runtime contact images are in `kinetic/screenshots/`. Route images are in
`art-pass/`. Extra scene images are in `expansion/screenshots/`.

This evidence copy includes PNG/JPEG images, JSON/JSONL data, and Markdown.
It excludes video and reference footage. Source paths and recorded video
paths in reports refer to the separate `inkline-showcase-source.zip` archive.
