# INKLINE 3D/characters

Original assets for RUN. Keep License.txt with redistributed files.

12 GLB models. Units are meters. Coordinates are +Y up and +Z forward.
Models use unlit materials. Dimensions and tags are in 3D/characters/Source/manifest.json.

- stick-standard: Stick Core
- stick-runner: Stick Runner
- stick-fighter: Stick Duelist
- stick-tall: Stick Staff Adept
- stick-compact: Stick Scrapper
- stick-heavy: Stick Heavy
- stick-scout: Stick Scout
- stick-acrobat: Stick Acrobat
- stick-worker: Stick Worker
- stick-agent: Stick Agent
- stick-striker: Stick Striker
- stick-sentinel: Stick Sentinel

Each character has 85 clips and an 18-bone rig. Source contains editable Blender files, generators, runtime code, and reuse instructions.
