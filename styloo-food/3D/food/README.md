# 3D Food

Artwork by **styloo**. [Original listing](https://styloo.itch.io/3dfood).

129 low-poly food models with 512-pixel hand-painted textures.

The original glTF files, binary buffers and textures stay together. Use unlit materials for the intended painted colors. Some one-sided surfaces may need double-sided rendering.

Original filenames, image dimensions and related file paths are preserved.
