# SunnyLand

Artwork by **ansimuz**. [Original listing](https://ansimuz.itch.io/sunny-land-pixel-game-art).

Animated fox, frog, eagle and opossum characters, platformer environments, props and effects.

Keep complete animation sheets and separate clips together. Frame timing is unspecified unless provided by the source. Pixel art uses nearest-neighbor filtering.

Original filenames, image dimensions and related file paths are preserved.
