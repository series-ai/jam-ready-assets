# Office Space

Artwork by **no2games**. [Original pack](https://opengameart.org/content/office-space-tileset).

Side-view office interiors: walls, doors, windows, stairs and furniture. The source describes layered 16 x 48 tiles.

The `Office-Interior-Walls-Doors/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
