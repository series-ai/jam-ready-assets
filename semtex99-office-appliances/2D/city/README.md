# Office Appliances

Artwork by **semtex99**. [Original pack](https://opengameart.org/content/indoor-office-appliances).

Office and factory interior decorations on a 32 x 32 pixel grid, including desks, cabinets, computers, lamps and stationery.

The `Office-Interior-Desks-Computers/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
