# Bountiful Bits

Artwork by **VEXED**. [Original listing](https://v3x3d.itch.io/bountiful-bits).

10 x 10 top-down tiles in colored and 1-bit editions, including natural terrain and buildings.

Each PNG is a complete sheet. Preserve its original tile grid and use nearest-neighbor filtering.

Original filenames, image dimensions and related file paths are preserved.
