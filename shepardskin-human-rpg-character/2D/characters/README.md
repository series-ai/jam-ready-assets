# Human Rpg Character

Artwork by **Shepardskin**. [Original pack](https://opengameart.org/content/human-rpg-character).

Civilian character with four-direction walking and blinking portraits. Original GIF sheets, individual frames and animations are included at original and 3x sizes.

The `Civilian-Walk-Portraits/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
