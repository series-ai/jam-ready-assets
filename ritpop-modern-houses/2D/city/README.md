# Modern Houses

Artwork by **Ritpop**. [Original pack](https://opengameart.org/content/modern-houses-tileset-topdown).

Top-down modern home tiles, with walls, windows, kitchen appliances, bathroom fixtures, beds and furniture.

The `Modern-Home-Interior-Furniture/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
