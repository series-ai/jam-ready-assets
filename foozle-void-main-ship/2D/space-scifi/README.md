# Void: Main Ship

Artwork by **Foozle / Chroma Dave**. [Original listing](https://foozlecc.itch.io/void-main-ship).

A spaceship with animated engines, shields and weapons.

Original sprite sheets and Aseprite sources are kept together. Load a full sheet with source rectangles; separate engine, shield and weapon layers can be composed as documented by the source. Read clip timing from the supplied Aseprite sources; no separate text timing guide is supplied.

Original filenames, image dimensions and related file paths are preserved.
