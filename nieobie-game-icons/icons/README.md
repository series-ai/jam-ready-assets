# Game Icon Pack

Artwork by **Nieobie**. [Original listing](https://nieobie.itch.io/free-icons).

815 rounded icons in 12 categories. The runtime set uses the original unpadded black 256-pixel PNGs.

All supplied PNG sizes, white variants, padding variants and SVG sources remain available in Source/OriginalPNG.7z and Source/OriginalSVG.7z. The runtime images are independent icons.

Original filenames, image dimensions and related file paths are preserved.
