# Isometric Town

Artwork by **Screaming Brain Studios**. [Original listing](https://screamingbrainstudios.itch.io/iso-town-pack).

443 isometric building and roof tiles in two lighting directions.

Complete sheets are preserved. Building tiles use a 64 x 96 grid and roofing uses 143 x 92. The source teal backgrounds remain unchanged; use color-key transparency when rendering.

Original filenames, image dimensions and related file paths are preserved.
