# Cant Stop Now — Launcher pack (by Barker)

Fling/launcher-game art, painted cartoon style, sunset palette.

- `hero.png` + `hero.json` — round blue daredevil with 8 emote faces
  (rest, happy, nervous, scream, 4 hurt variants)
- `slimetint1-6.png` + `slime_walk.json` — six pre-tinted ground slimes,
  11-frame walk cycle each (256px cells, same layout on every sheet)
- `jelly.png`, `balloon.png`, `spikemine.png` — flight objects
- `bench.png` (+ `bench_trim.png`, transparent margins removed) — launch pad
- `coin.png` + `coin.json` — 10-frame coin spin sheet; `coin_static.png` = frame 1
- Background layers (parallax, tile horizontally): `city_bg2.png` (rows above
  y=260 are opaque black — crop or sink below the horizon), `hills_bg2.png`
  (+ `hills_tile2.png`), `ground_strip2.png` (+ `ground_tile2.png`), `cloud2.png`
