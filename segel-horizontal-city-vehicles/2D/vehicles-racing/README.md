# Horizontal City Vehicles

Artwork by **Segel**. [Original pack](https://opengameart.org/content/2d-horizontal-car).

Side-view city vehicles: two cars, a box truck, a bus, a taxi and a truck, each with ten original PNG frames.

The `City-Traffic-Cars-Bus-Taxi-Trucks-Animations/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.

The numbered PNG files form related frame sequences. Import this pack as a group
to keep every vehicle animation together; individual frames are not standalone selections.
