# 2D Car Pack

Artwork by **Devil's Workshop**. [Original pack](https://opengameart.org/content/2d-car-pack-0).

Police car, civilian cars, pickup trucks and bus sprites in isometric, side/front and top views. Original individual PNGs, sheets and CSS coordinates are kept together.

The `City-Traffic-Vehicles/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.

Numbered vehicle views can be used independently. Each `Spritesheet-Frames/`
folder keeps the complete sprite sheets together with their original CSS coordinates.
Those related files stay available through whole-pack import. No sheet is cut into tiles.
