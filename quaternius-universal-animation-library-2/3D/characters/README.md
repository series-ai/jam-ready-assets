# Universal Animation Library 2 (Standard)

Artwork by **Quaternius**. [Original listing](https://quaternius.com/packs/universalanimationlibrary2.html).

A rigged mannequin carrying 43 animation clips. `UAL2_Standard.glb` has root motion disabled; `UAL2_Standard_RM.glb` has root motion baked into every clip.

`Mannequin_F.glb` is a female mannequin on the same rig, with no clips of its own. Both mannequins share bone names and close proportions, so the clips in either library file play on it.
