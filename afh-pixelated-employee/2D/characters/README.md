# Pixelated Employee

Artwork by **AFH**. [Original pack](https://opengameart.org/content/pixelated-employee-character).

Office employee with briefcase, idle and walk animations on a 24 x 24 pixel grid.

The `Office-Employee-Idle-Walk/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
