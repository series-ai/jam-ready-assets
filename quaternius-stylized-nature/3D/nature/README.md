# Stylized Nature MegaKit

Artwork by **Quaternius**. [Original listing](https://quaternius.com/packs/stylizednaturemegakit.html).

The free Standard edition: 68 tree, flower, plant, rock and ground models with original textures.

Keep each glTF, binary buffer and texture together. This edition contains the Standard models; the listing image shows that same edition. Source-only engine shaders are outside this download.

Original filenames, image dimensions and related file paths are preserved.
