# Officer Character

Artwork by **Chasersgaming**. [Original pack](https://opengameart.org/content/officer-character).

Police officer animation sheets at 32 x 32 pixels per frame. The boxed sheet includes animation labels; the unboxed sheet contains the sprites.

The `Police-Officer-Animations/` folder preserves the original asset filenames and pixel dimensions.
Use nearest-neighbor filtering for pixel art. Read the original sheet layout before
selecting animation frames; these files have not been cut or repacked.
